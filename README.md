# AdaptiveMACD – סורק חציית MACD בשלושה טווחי זמן

תהליך יומי שסורק את כל המניות הרשומות בארה"ב (NASDAQ, NYSE, NYSE American ועוד) ומחזיר רשימת מניות
שבהן **קו ה-MACD חוצה את קו ה-Signal כלפי מעלה בו-זמנית בגרף החודשי, השבועי והיומי**.

## הקריטריון

MACD סטנדרטי (12, 26, 9) על מחירי סגירה מותאמים:

* `MACD = EMA12 − EMA26`, `Signal = EMA9(MACD)`, `Histogram = MACD − Signal`
* **חצייה כלפי מעלה** בנר מסוים: בנר הקודם MACD היה מתחת/על ה-Signal (היסטוגרמה ≤ 0) ובנר הנוכחי מעליו (היסטוגרמה > 0).
* מניה עוברת את הסינון רק אם בכל שלושת טווחי הזמן:
  1. החצייה קרתה בתוך חלון ה-`lookback` שהוגדר (ברירת מחדל: 5 ימים / 2 שבועות / 2 חודשים), **וגם**
  2. ה-MACD עדיין מעל ה-Signal כרגע ("MACD פתוח"), **וגם**
  3. בנר החצייה קו ה-MACD היה **מתחת ל-0** (חצייה באזור השלילי – היפוך מירידה). ניתן לכבות את התנאי בנפרד לכל טווח.
* הנר השבועי והחודשי נבנים מהנתונים היומיים, והנר הנוכחי (שבוע/חודש שעדיין לא נסגר) נכלל – בדיוק כפי
  שהוא מוצג בגרף. כלומר "חצייה חודשית" = בחודש הקודם MACD היה מתחת ל-Signal, ונכון להיום החודש הנוכחי מעליו.
* אופציונלי `--require-acceleration`: דורש גם שההיסטוגרמה תגדל ביחס לנר הקודם בכל שלושת הטווחים (תאוצה).

סינון בסיסי: רק מניות רגילות (ללא ETF, וורנטים, יחידות, זכויות ומניות בכורה), מחיר ≥ $1,
ממוצע מחזור 50 יום ≥ 50,000 מניות. הכול ניתן לשינוי.

## הרצה מקומית

```bash
pip install -r requirements.txt
python -m screener.scan                       # כל השוק (~6,000 מניות, כ-10 דקות)
python -m screener.scan --tickers AAPL NVDA   # מניות ספציפיות
python -m screener.scan --help                # כל האפשרויות
```

אפשרויות עיקריות:

| דגל | ברירת מחדל | משמעות |
|---|---|---|
| `--daily-lookback N` | 5 | החצייה היומית קרתה ב-N הנרות היומיים האחרונים |
| `--weekly-lookback N` | 2 | החצייה השבועית קרתה ב-N הנרות השבועיים האחרונים |
| `--monthly-lookback N` | 2 | החצייה החודשית קרתה ב-N הנרות החודשיים האחרונים |
| `--daily-below-zero` / `--no-daily-below-zero` | פעיל | MACD מתחת ל-0 בנר החצייה היומי |
| `--weekly-below-zero` / `--no-weekly-below-zero` | פעיל | MACD מתחת ל-0 בנר החצייה השבועי |
| `--monthly-below-zero` / `--no-monthly-below-zero` | פעיל | MACD מתחת ל-0 בנר החצייה החודשי |
| `--require-acceleration` | כבוי | דרישה שההיסטוגרמה תגדל בכל טווח |
| `--closed-bars-only` | כבוי | התעלמות מהשבוע/חודש שעדיין לא נסגר |
| `--min-price` | 1.0 | מחיר מינימלי |
| `--min-avg-volume` | 50000 | ממוצע מחזור 50 יום מינימלי |
| `--include-etfs` | כבוי | הכללת ETF |

ברירת המחדל: החצייה היומית קרתה ב-5 הימים האחרונים, והשבועית והחודשית ב-2 הנרות האחרונים (הנוכחי או הקודם),
וה-MACD עדיין מעל ה-Signal בכל הטווחים. לתנאי המחמיר (חצייה בנר הנוכחי בלבד בכל הטווחים):
`--daily-lookback 1 --weekly-lookback 1 --monthly-lookback 1` – נדיר מאוד, ובימים רבים יתקבלו 0 תוצאות.

כל טווח זמן מוגדר באופן בלתי תלוי. לדוגמה, MACD מתחת ל-0 רק בחודשי ובשבועי, עם חלון יומי של 10 ימים:
`python -m screener.scan --no-daily-below-zero --daily-lookback 10`

## פלט

בתיקיית `results/`:

* `YYYY-MM-DD.csv` – תוצאות היום (כולל ערכי MACD/Signal/Histogram ומספר הנרות מאז החצייה לכל טווח)
* `latest.csv`, `latest.md` – התוצאה האחרונה

## הרצה יומית אוטומטית

`.github/workflows/daily-scan.yml` מריץ את הסריקה בכל יום מסחר (שני–שישי) ב-22:30 UTC, אחרי סגירת
המסחר, מעלה את התוצאות כ-artifact, מציג אותן בסיכום הריצה ומבצע commit לתיקיית `results/`.
אפשר גם להריץ ידנית מלשונית **Actions → Daily MACD scan → Run workflow** ולהעביר פרמטרים נוספים.

> GitHub מריץ workflows מתוזמנים רק מה-branch הראשי (default branch) של הריפו.
