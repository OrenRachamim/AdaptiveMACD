# AdaptiveMACD – סורק חציית MACD במספר טווחי זמן

תהליך יומי שסורק את כל המניות הרשומות בארה"ב (NASDAQ, NYSE, NYSE American ועוד) ומחזיר רשימת מניות
שבהן **קו ה-MACD חוצה את קו ה-Signal כלפי מעלה בו-זמנית בגרף החודשי והיומי** (ברירת מחדל).
אפשר להוסיף גם את הגרף השבועי עם `--timeframes monthly weekly daily`.

## תחזית הצטלבות יומית (הריצה היומית)

הריצה היומית (`python -m screener.cross_scan`) מחפשת מניות שה-MACD היומי שלהן עדיין **מתחת** ל-Signal
והקווים **עדיין לא נוגעים** (פער של יותר מ-5% מערך ה-Signal), אבל צפוי להגיע ל-Signal – לנגוע בו
(פער ≤ 5%) או לחצות אותו – **בסגירה הבאה**, בסיכוי של 70% ומעלה. בבדיקה על 2015–2026, כ-82% מהמניות
ברשימה אכן נגעו/חצו למחרת (79%–83% בכל שנה). `--mode cross` מחזיר את התחזית להצטלבות בלבד.

* **מחיר ההצטלבות:** ה-MACD הוא פונקציה לינארית של מחיר הסגירה, ולכן לכל יום יש מחיר סגירה מדויק שמעליו
  הקווים יצטלבו מחר.
* **הסיכוי:** השינוי הנדרש עד מחיר ההצטלבות מחולק בתנודתיות היומית של המניה (סטיית תקן של 60 יום),
  ומתורגם לסיכוי לפי טבלת כיול שנבנתה על 2.46 מיליון ימי מסחר היסטוריים
  (`screener/data/daily_cross_calibration.csv`).
* **דיוק בבדיקה על 2015–2026 (נתונים שלא שימשו לבניית המודל):** בסף 70%, כ-82% מהמניות ברשימה אכן הצטלבו
  למחרת, בעקביות בכל שנה (81%–85%). הוספת מצב שבועי/חודשי לא שיפרה את הדיוק.
* זו תחזית לכך שהקווים יצטלבו – לא לכך שהמחיר ימשיך לעלות.

| דגל | ברירת מחדל | משמעות |
|---|---|---|
| `--min-prob` | 0.70 | סף הסיכוי |
| `--mode` | touch | `touch` = רגע לפני נגיעה, `cross` = רגע לפני הצטלבות |
| `--tolerance` | 0.05 | מתי הקווים נחשבים "נוגעים" (פער כחלק מ-\|Signal\|) |
| `--tickers` | – | סריקת מניות ספציפיות |
| `--min-price` / `--min-avg-volume` | 1 / 50,000 | סינון בסיסי |

## סורק החציות המקורי

## הקריטריון

MACD סטנדרטי (12, 26, 9) על מחירי סגירה (מותאמים לפיצולים בלבד):

* `MACD = EMA12 − EMA26`, `Signal = EMA9(MACD)`, `Histogram = MACD − Signal`
* **חצייה כלפי מעלה** בנר מסוים: בנר הקודם MACD היה מתחת/על ה-Signal (היסטוגרמה ≤ 0) ובנר הנוכחי מעליו (היסטוגרמה > 0).
* מניה עוברת את הסינון רק אם בכל אחד מטווחי הזמן שנבחרו:
  1. החצייה קרתה בתוך חלון ה-`lookback` שהוגדר (ברירת מחדל: 5 ימים / 2 שבועות / 2 חודשים), **וגם**
  2. ה-MACD עדיין מעל ה-Signal כרגע ("MACD פתוח"), **וגם**
  3. בנר החצייה קו ה-MACD היה **מתחת ל-0** (חצייה באזור השלילי – היפוך מירידה). ניתן לכבות את התנאי בנפרד לכל טווח, **וגם**
  4. הפער בין MACD ל-Signal כרגע הוא לפחות 5% מגודל ה-Signal (סינון חציות זעירות), **וגם**
  5. אין "הלוך-חזור" (whipsaw) – הקווים לא חצו זה את זה יותר מפעם אחת בתוך חלון ה-lookback.
* הנר השבועי והחודשי נבנים מהנתונים היומיים, והנר הנוכחי (שבוע/חודש שעדיין לא נסגר) נכלל – בדיוק כפי
  שהוא מוצג בגרף. כלומר "חצייה חודשית" = בחודש הקודם MACD היה מתחת ל-Signal, ונכון להיום החודש הנוכחי מעליו.
* אופציונלי `--require-acceleration`: דורש גם שההיסטוגרמה תגדל ביחס לנר הקודם בכל שלושת הטווחים (תאוצה).

סינון בסיסי: רק מניות רגילות (ללא ETF, וורנטים, יחידות, זכויות ומניות בכורה), מחיר ≥ $1,
ממוצע מחזור 50 יום ≥ 50,000 מניות. הכול ניתן לשינוי.

## הרצה מקומית

```bash
pip install -r requirements.txt
python -m screener.scan                       # כל השוק (~6,000 מניות, כ-10 דקות)
python -m screener.scan --tickers AAPL NVDA   # מניות ספציפיות
python -m screener.scan --help                # כל האפשרויות
```

אפשרויות עיקריות:

| דגל | ברירת מחדל | משמעות |
|---|---|---|
| `--timeframes ...` | monthly daily | אילו טווחי זמן נבדקים. כברירת מחדל השבועי לא נבדק; להוספתו: `--timeframes monthly weekly daily` |
| `--daily-lookback N` | 5 | החצייה היומית קרתה ב-N הנרות היומיים האחרונים |
| `--weekly-lookback N` | 2 | החצייה השבועית קרתה ב-N הנרות השבועיים האחרונים |
| `--monthly-lookback N` | 2 | החצייה החודשית קרתה ב-N הנרות החודשיים האחרונים |
| `--daily-below-zero` / `--no-daily-below-zero` | פעיל | MACD מתחת ל-0 בנר החצייה היומי |
| `--weekly-below-zero` / `--no-weekly-below-zero` | פעיל | MACD מתחת ל-0 בנר החצייה השבועי |
| `--monthly-below-zero` / `--no-monthly-below-zero` | פעיל | MACD מתחת ל-0 בנר החצייה החודשי |
| `--daily-min-hist-pct` / `--weekly-min-hist-pct` / `--monthly-min-hist-pct` | 5 | פער מינימלי MACD מעל Signal, באחוזים מ-\|Signal\| (0 = כבוי) |
| `--allow-whipsaw` | כבוי | לקבל גם חציות הלוך-חזור בתוך החלון |
| `--adjust-dividends` | כבוי | חישוב על מחירים מותאמים לדיבידנד (ברירת מחדל: מותאמים לפיצולים בלבד, כמו בגרף רגיל) |
| `--require-acceleration` | כבוי | דרישה שההיסטוגרמה תגדל בכל טווח |
| `--closed-bars-only` | כבוי | התעלמות מהשבוע/חודש שעדיין לא נסגר |
| `--min-price` | 1.0 | מחיר מינימלי |
| `--min-avg-volume` | 50000 | ממוצע מחזור 50 יום מינימלי |
| `--include-etfs` | כבוי | הכללת ETF |

ברירת המחדל: החצייה היומית קרתה ב-5 הימים האחרונים, והשבועית והחודשית ב-2 הנרות האחרונים (הנוכחי או הקודם),
וה-MACD עדיין מעל ה-Signal בכל הטווחים. לתנאי המחמיר (חצייה בנר הנוכחי בלבד בכל הטווחים):
`--daily-lookback 1 --weekly-lookback 1 --monthly-lookback 1` – נדיר מאוד, ובימים רבים יתקבלו 0 תוצאות.

כל טווח זמן מוגדר באופן בלתי תלוי. לדוגמה, MACD מתחת ל-0 רק בחודשי ובשבועי, עם חלון יומי של 10 ימים:
`python -m screener.scan --no-daily-below-zero --daily-lookback 10`

## פלט

בתיקיית `results/`:

* `YYYY-MM-DD.csv` – תוצאות היום (כולל ערכי MACD/Signal/Histogram ומספר הנרות מאז החצייה לכל טווח)
* `latest.csv`, `latest.md` – התוצאה האחרונה

## הרצה יומית אוטומטית

`.github/workflows/daily-scan.yml` מריץ את הסריקה בכל יום מסחר (שני–שישי) ב-22:30 UTC, אחרי סגירת
המסחר, מעלה את התוצאות כ-artifact, מציג אותן בסיכום הריצה ומבצע commit לתיקיית `results/`.
אפשר גם להריץ ידנית מלשונית **Actions → Daily MACD scan → Run workflow** ולהעביר פרמטרים נוספים.

> GitHub מריץ workflows מתוזמנים רק מה-branch הראשי (default branch) של הריפו.

## שליחה לטלגרם

בסוף כל ריצה יומית התוצאות נשלחות להודעת טלגרם: לכל מניה מופיעים קישור לגרף ב-TradingView, מחיר סגירה,
מחזור ממוצע ומועדי החצייה בכל טווח. גם ביום בלי תוצאות נשלחת הודעה קצרה.

הגדרה חד-פעמית:

1. בטלגרם, פתח צ'אט עם **@BotFather**, שלח `/newbot` וקבל **token**.
2. שלח לבוט החדש הודעה כלשהי (למשל `/start`). כדי לשלוח לקבוצה או לערוץ – הוסף אליהם את הבוט.
3. מצא את ה-**chat id**: פתח בדפדפן `https://api.telegram.org/bot<TOKEN>/getUpdates` וחפש `"chat":{"id":...}`.
4. בריפו ב-GitHub: **Settings → Secrets and variables → Actions → New repository secret** והוסף:
   * `TELEGRAM_BOT_TOKEN` – ה-token מ-BotFather
   * `TELEGRAM_CHAT_ID` – ה-chat id

בלי ה-secrets האלה שלב הטלגרם פשוט מדולג. בדיקה מקומית בלי לשלוח: `python -m screener.notify_telegram --dry-run`.
